# راهنمای فرانت‌اند: خدمات رزرو مشاوره

## خلاصه تغییر

هر رزرو از این پس فیلد `dentalServices` را به‌صورت آرایه دارد و امکان انتخاب هم‌زمان چند خدمت وجود دارد. مقادیر معتبر عبارت‌اند از:

| مقدار عددی | نام enum | عنوان نمایشی |
|---:|---|---|
| `1` | `Composite` | کامپوزیت |
| `2` | `Implant` | ایمپلنت |
| `3` | `Laminate` | لمینت |

> تنظیم فعلی JSON در بک‌اند enumها را عددی ارسال و دریافت می‌کند؛ بنابراین فرانت باید از آرایه اعداد استفاده کند.

## ایجاد رزرو توسط مشاور

در درخواست `POST /api/Reservation` فیلد زیر الزامی است و باید دست‌کم یک مقدار معتبر داشته باشد:

```json
{
  "leadAssignmentId": 123,
  "consultantProfileId": 45,
  "reservationAt": "2026-08-25T10:30:00Z",
  "dentalServices": [1, 2]
}
```

مقادیر تکراری در بک‌اند حذف می‌شوند. آرایه خالی یا مقدار خارج از `1` تا `3` با پاسخ ناموفق و پیام «انتخاب حداقل یک خدمت معتبر الزامی است» رد می‌شود.

## ویرایش توسط مشاور

در `PUT /api/Reservation/ConsultantReservations/{reservationId}`، فیلد `dentalServices` را همراه سایر فیلدهای فرم بفرستید:

```json
{
  "reservationAt": "2026-08-26T09:00:00Z",
  "description": "توضیحات رزرو",
  "dentalServices": [1, 3]
}
```

## ویرایش توسط منشی

در `PATCH /api/Reservation/SecretaryReservations/{reservationId}/time` منشی می‌تواند زمان و خدمات را با هم ویرایش کند:

```json
{
  "reservationAt": "2026-08-27T11:00:00Z",
  "dentalServices": [2, 3]
}
```

مسیر عمومی `PUT /api/Reservation` نیز فیلد `dentalServices` را می‌پذیرد. در APIهای ویرایش، نبودن فیلد یا ارسال `null` خدمات قبلی را بدون تغییر نگه می‌دارد؛ ارسال آرایه، کل انتخاب قبلی را جایگزین می‌کند. آرایه خالی معتبر نیست.

## نمایش در داشبوردها

فیلد `dentalServices` در پاسخ‌های زیر اضافه شده است:

- پاسخ ایجاد رزرو؛
- `GET /api/Reservation/GetConsultantReservations` برای مشاور؛
- `GET /api/Reservation/SecretaryReservations` و `GET /api/reservations` برای منشی/ادمین؛
- گزارش روزانه رزروهای ادمین.

نمونه آیتم پاسخ:

```json
{
  "reservationId": 987,
  "patientName": "بیمار نمونه",
  "dentalServices": [1, 2, 3]
}
```

برای نمایش، آرایه را با جدول enum بالا به برچسب فارسی تبدیل کنید. در فرم ایجاد و ویرایش از کنترل چندانتخابی یا سه checkbox استفاده شود و پیش از ثبت، وجود حداقل یک انتخاب کنترل گردد.

خروجی CSV رزروها و گزارش روزانه ادمین نیز ستون «خدمات» را با عناوین فارسی و جداکننده «،» دارد.

## استقرار بک‌اند

پیش از انتشار نسخه جدید API، migration جدید دیتابیس اجرا شود:

```bash
dotnet ef database update \
  --project DentalDashboard.Infrastracture \
  --startup-project DentalDashboard
```

برای رزروهای قدیمی مقدار اولیه `[]` ثبت می‌شود. فرانت باید حالت آرایه خالی را برای داده‌های قدیمی با متن «خدمت ثبت نشده» نمایش دهد.
